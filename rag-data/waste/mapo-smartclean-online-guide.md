## 대상 품목
- 가전제품류(텔레비전, 냉장고, 세탁기 등), 가구류(장롱, 침대, 책상 등), 생활용품류(거울, 항아리, 세면대 등).
- 종량제봉투에 담기 어려운 생활폐기물.

## 배출 신청 절차
1. 배출신청 페이지로 이동
2. 신고자 정보 입력 및 휴대폰 인증
3. 배출 장소와 일시 입력
4. 배출 품목 선택
5. 수수료 결제
6. 배출증을 출력하거나 손으로 작성해 배출 물품에 부착(필수), 사진 업로드(선택)
7. 배출 장소에 배출

## 배출 취소 절차
1. 결과조회 / 배출취소 페이지로 이동
2. 신고자 정보 입력 후 휴대폰 인증
3. 신청한 주문번호 선택
4. 취소할 품목을 선택해 취소

## 수수료
- 이 페이지에는 금액 없음. 별도 '수수료 안내' 페이지에서 확인(본 수집에서는 열지 않음).
