## 신고방법
- 인터넷: 대형폐기물 배출 신청 사이트(smartclean.gwanak.go.kr)에서 신청.
- 전화: 콜센터 02-882-5677 접수.

## 수수료
- 이 페이지에는 금액 없음.
- 인터넷 신청: 카드, 계좌이체, 가상계좌 결제. 전화 신청: 가상계좌 무통장 입금.

## 수거절차
- 인터넷 신청: 신청서 작성 → 수수료 결제 → 결제 확인 후 배출번호 발급 → 배출번호를 기재하거나 배출증을 출력해 부착, 건물 밖 1층 배출장소에 배출 → 신청내역 확인 후 수거.
- 전화 신청: 콜센터 접수 → 가상계좌 입금 → 결제 확인 후 배출번호 발급 → 배출번호 기재 후 건물 밖 1층 배출장소에 배출 → 신청내역 확인 후 수거.

## 무상수거
- 이 페이지에는 없음. 같은 메뉴 '대형폐가전 무상배출'은 별도 페이지(gwanak-large-appliance-free-disposal.md 참고).
