서울시 조직도 페이지의 구조 요약. 기준일은 페이지에 없음(페이지의 날짜는 웹접근성 인증 기간으로 기준일이 아님). 과 상세 업무는 JavaScript 링크로만 연결되어 열람하지 못했다. 규모: 3부시장 6실 5본부 33국·관·단.

| 상위 조직 | 하위 과 |
|---|---|
| 기후환경본부 | 기후환경정책과, 녹색에너지과, 친환경건물과, 친환경차량과, 대기정책과, 자원회수시설추진단(자원순환과, 자원회수시설과, 생활환경과) |
| 교통실 교통기획관 | 교통정책과, 도시철도과, 버스정책과, 미래첨단교통과, 택시정책과 |
| 교통실 교통운영관 | 주차계획과, 생활교통안전과, 교통운영과, 자전거PM과, 물류환승과 |
| 행정국 | 총무과, 인사과, 인력개발과, 자치행정과, 국제행사지원과, 시민협력과, 대외협력과 |
| 홍보기획관 | 홍보담당관, 콘텐츠담당관, 서울브랜드담당관, 민원담당관 |
